# China Semiconductor Tracker

An interactive, open-source tracker for mainland China's semiconductor manufacturing footprint — fabs, memory makers, OSAT/advanced-packaging sites, compound-semiconductor lines, and research/pilot fabs — plus the chip design firms and equipment/materials companies it depends on.

**Live site:** [fabs-china.pranaykotas.com](https://fabs-china.pranaykotas.com)

Maintained by [Pranay Kotasthane](https://pranaykotas.com) at the [Takshashila Institution](https://takshashila.org.in). Part of the [Siliconpolitik Project](https://takshashila.org.in/pages/research-areas/focus-areas/siliconpolitik.html). Sibling project: [India Semiconductor Tracker](https://github.com/pranaykotas/india-semiconductor-tracker).

---

## What It Tracks

- **42 facilities** across 25+ provinces/municipalities — State-Backed, Private, JV, and Foreign-Invested
- **Status** (Announced → Approved → Under Construction → Operational), per-phase where a site's phases move at different speeds
- **Capability & node trajectory** — wafer size, process nodes, product focus
- **Investment** in ¥亿 (RMB 100M) and/or USD as disclosed, with the funding source named
- **US designations** where applicable — Commerce/BIS Entity List vs DoD Section 1260H, kept distinct
- **Milestones and sources for every entry** — Chinese-language industry coverage (集微网, 财联社, 芯智讯, 电子工程专辑, 交易所 filings) alongside international outlets

## The Data

Source of truth is `data/facilities.yml`, `data/design.yml`, and `data/materials.yml`. Site pages are generated by the R scripts in `R/` and rendered with Quarto.

## How to Contribute

The tracker depends on community contributions to stay accurate. There are two ways:

### Option 1 — Email (no account needed)

**Email pranay@takshashila.org.in** with the subject "China Semiconductor Tracker — update" (the site's "Have an update?" button prefills this). Use it for:
- Status changes (construction started, line-out 通线, production begun)
- Corrections to investment figures, capacity, dates, or descriptions
- New facility announcements

### Option 2 — GitHub Issue (for detailed contributions)

**[Open an Issue](https://github.com/pranaykotas/china-semiconductor-tracker/issues/new/choose)** using the facility or design-firm template. Include:
- Which facility/firm (or details of a new one)
- What changed
- A source URL — company announcement, SSE/SZSE filing, or credible news report (Chinese sources are fully welcome)

All submissions are reviewed against the tracker's sourcing standard before being merged into the YAML data. Updates are incorporated weekly.

## Automation

GitHub Actions keeps the site and its maintainer current:

- **`weekly-digest.yml`** — every Monday, trawls Google News (Chinese zh-CN + English editions) for ~35 facility-specific queries, diffs the results against the live `data/facilities.yml` with Claude, and emails a "what changed this week" digest with suggested YAML edits.
- **`deploy.yml`** — rebuilds and deploys the Quarto site to GitHub Pages weekly and on merge.
